# Rumbo Sur - Trabajo Práctico Final

Migración a React del proyecto académico **Rumbo Sur**, realizada con React + Vite.

## Requisitos incluidos
- Componentes reutilizables.
- Props en las tarjetas de viajes.
- Formulario controlado con `useState`.
- `preventDefault()` en el envío.
- `console.log` de eventos de inputs y datos enviados.
- Botón para reiniciar el formulario.
- React Router con ruta principal `/`.
- Diseño responsive heredado del proyecto original.

## Ejecutar el proyecto
1. Abrir esta carpeta en Visual Studio Code.
2. Abrir una terminal.
3. Ejecutar `npm install`.
4. Ejecutar `npm run dev`.
5. Abrir la URL local que muestra Vite (normalmente `http://localhost:5173`).

## Build
`npm run build`
